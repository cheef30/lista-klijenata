# Lista klijenata

Lista od 180 lokalnih biznisa (143 iz Obrenovca i okoline, ostali iz ostatka Srbije) kojima mogu da ponudim izradu sajta, sa kontaktom, statusom sajta i porukom za svakog.

- `index.html` – stranica sa filterima, kopiranjem poruka i praćenjem statusa (status se čuva u pregledaču)
- `data.json` – svi podaci u JSON formatu
- `leads.py` + `gen.py` – izvorni podaci i generator poruka (`python3 gen.py`, pa ponovo ubaci JSON u `index.html`)

Otvori preko GitHub Pages: https://cheef30.github.io/lista-klijenata/
